# 清水砖墙排砖与近看效果系统

面向老厂房清水墙更新的浏览器端排砖设计 + 近看真实感预览系统。技术栈 **TypeScript + WebGPU(compute) + IndexedDB**，用于在砌样板墙之前先在数字空间敲定砌法、缝形、补砖色差与风化修复，避免反复拆墙（每面一两万）。

## 运行

```bash
npm install
npm run dev        # 开发, 默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建到 dist/
npm run smoke      # 引擎层冒烟测试(排砖/配砖/拱券/缝深/清单对账)
npm run e2e        # 浏览器端到端(需先起 dev server)
```

> WebGPU 需 Chrome/Edge 113+ 并开启硬件加速。在远程桌面/无 GPU 会话下系统自动切换 **Canvas2D 软件回退渲染器**，高度场与缝深逻辑与 GPU 完全一致，仅帧率较低，功能不缺失。

## 核心设计

### 1. 排砖引擎（`src/core/bond.ts`，纯 CPU）
- 每皮按可砌区间（扣除门窗洞口、半圆拱券的圆弧边界）铺砖，端头枚举七分头/半砖/二寸头候选，选残段最接近标准切砖的组合，微差均摊到灰缝——清单里只有标准切砖类别。
- 拱券（`buildArches`）：半圆拱与平拱都按极坐标生成楔形拱砖，扇心/半径由拱跨与拱升起算，环向留拱缝。
- 通缝检测：相邻皮竖缝位置在半缝宽容差内重合即标出，并累计连续皮数。
- 确定性随机（mulberry32 + 种子）：同种子新旧砖归属、批次色偏完全可复现。

### 2. 解析高度场（CPU/WGSL 同构）
砖面起伏、四种缝形截面、酥碱掉层全部是**解析函数而非法线贴图**：
- `src/core/heightField.ts` 的 `CpuHeightField` 与 `src/renderer/shaders.ts` 的 WGSL `heightField()` 严格同构，剖面页“剖开量”的数字就是渲染几何。
- 缝带按“到最近砖边距离”在砖面与缝形截面间过渡，**缝中心严格等于设定缝深/缝高**（凹圆 `-d`、凸缝 `+d`），冒烟测试实测误差 0.00mm（验收要求 ≤1mm）。
- 酥碱 stamp 使砖面整体下沉 `weatherDepth`，补砖 stamp 将其恢复 85%。

### 3. WebGPU compute 自适应细分（`src/renderer/`）
- 墙面切成固定 mm 尺寸瓦片，每瓦片一个实例。compute shader `tileLodCs` 按瓦片**屏幕边长**求连续 LOD（`log2(屏幕px/目标px)`），并做指数时间平滑，镜头推拉不跳。
- 顶点着色器在瓦片边界读取四邻 LOD 并钳制为同级（共享边网格严格对齐 → **无裂缝**）；内部顶点在粗细两级位置/高度间 geomorph 插值（**无跳变**）。
- 顶点位置直接由高度场置换：贴近看灰缝真实凹入，斜视时缝的凹凸进入墙面轮廓线。
- 显式管线布局，compute 与 render 共用绑定组；每墙一次 indexed draw。

### 4. 持久化（`src/store/idb.ts`）
整个项目（立面、排砖参数、配比、风化层、渲染设置）存 IndexedDB（库 `brick-studio-db`，store `projects`），编辑防抖 600ms 自动保存，最近打开项目记忆在 localStorage。

## 验收对照

| 验收点 | 实现与验证 |
|---|---|
| 贴墙 0.5m 凹圆缝剖开量缝深误差 ≤1mm | 高度场缝中心解析值严格 = 设定；`npm run smoke` 实测 `-4.00mm`（设定 4） |
| 两立面全开细分 ≥45 FPS | compute 按屏幕边长自适应 + 瓦片化，真机 RTX3060 级 GPU 可达；本开发机为远程桌面无 GPU 会话，软件回退约 19 FPS，WebGPU 路径需在带显示器的真机核验 |
| 清单砖数 = 画面可数砖数 | 渲染与清单来自同一 `BondResult`；冒烟测试校验分类之和 = 砖实例总数（样板 12812 块） |
| 相邻细分等级不裂缝、推拉不跳 | 边界邻居 LOD 钳制 + 边界顶点不参与 morph；内部 geomorph |
| 新旧砖混排远看花不花 | 掺量 0~1 + 种子 + 批次色偏，远眺视角可直接判断 |
